# FloorWatch 30층 업그레이드 — 설치와 검증 안내

## 현재 상태
기존 Cloudflare 프로젝트를 업그레이드하는 소스 코드입니다. 공개 사이트에 아직 배포하지 않았습니다.
GitHub 연결 권한이 없어 이 대화에서 저장소에 직접 반영하지 않았습니다.
흰색 메인 화면, 30층, 1~30층 카메라 선택, 사람 수와 이름 배열 송수신을 구현했습니다.

## 업로드 (기존 저장소 유지)
1. ZIP을 압축 해제합니다.
2. GitHub floorwatch 저장소에서 Add file → Upload files로 이동합니다.
3. 압축 해제된 폴더 **안의 내용 전체**를 업로드합니다. ZIP 자체나 바깥 폴더를 올리지 않습니다.
4. Commit changes로 저장합니다. 기존 파일은 새 버전으로 교체됩니다.
5. Cloudflare의 새 빌드에서 최신 커밋이 선택됐는지 확인합니다.
   빌드: pnpm run build
   배포: npx wrangler deploy --config dist/server/wrangler.json
6. 배포 성공 후 기존 사이트에서 강력 새로고침합니다.
7. 같은 현황 링크로 접속해 카메라를 시작하고 '현황 화면 열기'로 확인합니다.

## DB와 주소
wrangler.jsonc에 기존 floorwatch-db의 DB 바인딩과 workers_dev=true를 포함했습니다.
DB ID는 사용자가 제공한 화면의 173c65ca-da27-4e25-8095-45fcab20dfeb를 사용합니다.
다른 계정에 배포한다면 반드시 이 ID를 바꾸세요.
첫 API 호출 시 floor_signals_v2 표를 자동 생성합니다. 기존 floor_signals 표는 삭제하지 않습니다.
구버전과 새 버전은 다른 표를 쓰므로 모든 카메라 탭을 새로고침하세요.
되돌리려면 GitHub에서 업그레이드 커밋을 되돌려 재배포하세요. 기존 표는 남아 있습니다.

## 3대 시연
30층 모두에 카메라를 설치할 필요는 없습니다.
세 컴퓨터가 동일한 현황 링크를 열고 각자 1층, 15층, 30층을 선택하면 됩니다.
한 층에 카메라 1대만 사용하세요. 같은 층에서 두 송신기를 쓰면 마지막 전송이 덮어씁니다.
카메라 미연결은 사람이 없다는 뜻이 아닙니다. 12초 이상 신호가 없으면 연결 없음입니다.
브라우저 백그라운드/절전 상태에서는 타이머가 느려질 수 있어 시연 시 카메라 탭을 보이게 유지하세요.

## 전체 화면 한글 OCR: 제한된 실험 기능
OCR는 이미지에서 글자를 읽는 기능입니다. 얼굴 인식/신원 확인/안전모 착용 판정이 아닙니다.
이번 버전은 웹캠 전체 화면을 읽고, 공백·기호로 구분된 정확히 세 글자의 한글 문자열을 후보로 추출합니다.
\`안전모\`, \`작업자\`처럼 이름이 아닌 세 글자 낱말도 후보가 될 수 있으므로 이름을 확정하는 기능은 아닙니다.
여러 사람의 안전모 위치를 각각 찾는 안전모 탐지 모델은 구현되지 않았습니다.
1. 사람 감지를 시작합니다.
2. 전체 화면 OCR 켜기에 체크합니다. 모델 첫 다운로드에 시간이 걸릴 수 있습니다.
3. 이름표가 웹캠 화면에서 크고 밝고 수평으로 보이게 합니다.
4. 동일한 세 글자 후보 목록이 두 번 연속 판독되면 결과를 전송합니다.
5. 후보를 읽지 못하면 사람 수만 표시됩니다. 사람 수는 OCR로 계산하지 않습니다.
OCR 속도와 정확도는 실제 기기/조명/거리별로 검증해야 합니다.
작은 글씨, 곡면, 모션 블러, 어두운 환경은 학술제 전에 실험하세요.
OCR 종료/불확실/다인 장면에서는 새 신호에 이름을 넣지 않습니다.
화면은 2초 갱신하므로 이름 제거에도 전송·갱신 지연이 있습니다.

## 개인정보와 운영 제한
가명만 사용하세요. 이름을 허용 목록에 넣는 것 자체로 촬영 동의가 확인되는 것은 아닙니다.
원본 영상과 OCR 이미지가 서버로 전송되지는 않습니다.
Tesseract.js 코드와 한국어 모델은 외부 CDN에서 다운로드합니다.
확인된 가명/층/인원/시간은 Cloudflare DB에 마지막 값으로 저장됩니다.
실시간 화면에서 만료돼도 DB 기록은 자동 삭제되지 않습니다.
동의 철회/시연 종료 시 특정 현장 데이터를 삭제하려면 D1 Console에서:
DELETE FROM floor_signals_v2 WHERE room = '삭제할_현장_room값';
실행 전 대상 room을 반드시 확인하세요. SQL 삭제는 별도 백업 없이는 되돌리기 어렵습니다.
현황 링크는 비밀 열쇠처럼 취급하세요. 로그인/역할별 접근 제어가 없는 프로토타입입니다.
링크 보유자는 결과를 열람하거나 API로 신호를 입력할 수 있습니다.
실제 작업자 실명·실제 현장 배포에는 인증, 권한, 보존기간, 동의 관리가 필요합니다.
OCR는 안전보호구 착용 여부를 보장하지 않습니다. 안전 의사결정에 사용하지 마세요.

  잘못된 room 거부, 0명일 때 이름 제거, 12초 만료, 현장별 데이터 분리 통과
- React 서버 렌더링: 30개 층 행 생성 확인
- 실제 Cloudflare 배포 후 통합 테스트: 미실시 (계정 연결 필요)
- 실제 웹캠/한글 이름표 정확도: 미검증
- 화면 스크린샷 테스트: 실행 환경에 Chromium 미설치로 미실시
