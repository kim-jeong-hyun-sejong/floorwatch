# FloorWatch

학술제 시연용 3층 사람 감지 웹앱입니다. 각 컴퓨터의 웹캠 영상은 해당 브라우저 안에서 분석되며, 서버에는 시연 키·층·검출 인원·수신 시각만 전송됩니다.

## Cloudflare 빌드 설정

- 프로덕션 브랜치: `main`
- 빌드 명령: `npm run build`
- 배포 명령: `npx wrangler deploy --config dist/server/wrangler.json`
- 루트 디렉터리: 비워 둠

## D1 데이터베이스

배포 후 D1 데이터베이스를 만들고 Worker에 `DB`라는 이름으로 연결한 다음 `drizzle/0000_wonderful_umar.sql`을 실행해야 층별 신호 공유 기능이 작동합니다.

## 사용 방법

1. 현황 화면에서 `웹캠 연결하기`를 누릅니다.
2. 각 컴퓨터에서 담당 층을 서로 다르게 선택합니다.
3. `웹캠 연결 및 사람 감지 시작`을 누르고 카메라 권한을 허용합니다.
4. `현황 링크 복사`로 만든 동일한 링크를 발표 화면과 카메라 컴퓨터에서 사용합니다.

검출 결과는 한 장면에 보이는 사람 수이며 고유 작업자 수나 출입 인원을 의미하지 않습니다.
